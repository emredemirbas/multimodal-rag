# Explicit local visual probe

Date: 2026-10-26

This is the first **stateless MP4/frame/OCR component**, not video upload in the
application. It creates no project/source/job, stores no application objects and
publishes no retrieval/citation evidence. Existing SRT/VTT/WAV paths are unchanged.
No paid/cloud provider, arbitrary URL/video downloader or vision-description model.

## Build and exercise authored cards

```bash
docker compose build visual-inspect
docker compose --profile visual-tools run --rm -T --no-deps --entrypoint python \
  visual-inspect -m app.vision.selftest
```

Build explicitly installs local FFmpeg/Tesseract and Debian English/Turkish OCR
language packages. No Ollama/Whisper weights are downloaded and no model/setup
request happens at inference time. The minimal image contains only the visual
tool, its shared kernel filter and pinned Pydantic, not API/database/S3/Celery code.
Normal startup excludes this profile. Use `run` as shown, not `up`, and do not add
`visual-tools` to ordinary application profiles. The command exits when finished.

The self-test generates its own fixed high-contrast English/Turkish card video
inside the disposable tool container. It checks inherited socket denial, actual
PTS, PNG generation, exact duplicate removal and explicit `en`/`tr` recognition.
Its combined-language diagnostic is reported separately: `en+tr` missed the
Turkish exact terms in the initial native test. Explicit-language success is not
reclassified as universal multilingual accuracy; no representative benchmark or
scene/terminal/code-quality gate has passed.

## Process an owned/authorized file

```bash
docker compose --profile visual-tools run --rm -T --no-deps visual-inspect \
  --authorized-input --language tr < /absolute/path/to/owned-tutorial.mp4
```

Select `en` (default), `tr`, or experimental `en+tr`; language selection is explicit,
not automatic detection or fallback. The acknowledgement is the operator's rights
assertion, not independent license verification. Only bytes enter stdin: no host
directory, Docker socket, app credentials or application-data volumes are mounted.
**Your host input file is not deleted.** Temporary copies/intermediates are confined
to the container's bounded tmpfs, cleaned on completion/error, and destroyed with
the container. Frames/OCR are not exported by this command.

Supported initial subset:

- non-fragmented ISO MP4, <=100,000,000 bytes and 600 seconds;
- one H.264/avc1, 8-bit yuv420p video; 16–1920 x 16–1080, unrotated;
- constant 1–60 fps, zero-based video/container timeline;
- optional AAC audio is ignored, **not transcribed**; other tracks/codecs fail;
- at most 20 uniform candidates, one per five seconds on short clips;
- fit to 960x540 grayscale, actual decoded millisecond PTS, deterministic PNG;
- exact decoded-image deduplication only: no scene detector or perceptual grouping.

Unsupported/malformed input fails with a content-free error, not a downloader,
codec fallback, fake timestamp or partially published result. Recognized text is
literal untrusted input; it is never executed or interpreted as instructions.
OCR can miss code, punctuation and Turkish characters. Grayscale/downscaling and
uniform sampling can miss useful visual changes. Use permitted subtitles for the
normal product workflow while video ingestion is not connected.

## Output and isolation

The JSON summary includes input/frame SHA-256, video geometry/duration/frame rate,
requested/actual sampled times, candidate/unique/text-bearing counts and declared
engine/language-data profile. It does not print OCR text, pixels, host paths or
raw native errors. `quality_approval` always remains `not_established`; ordinary
`component-complete` means parsing finished, **not accurate OCR or indexed video**.
Treat hashes as content fingerprints; do not publish reports for private clips.

Uniform candidates use the source duration; image filenames are generated by
FFmpeg from copied decoded PTS under an explicit 1/1000 encoding time base. The
requested neighborhood is checked independently (at most one second ahead), even
for discarded duplicate frames. Actual timestamp/PNG hash is retained for each
kept frame. An intentionally narrow P5 parser validates decoded pixel bounds;
standard-library PNG encoding needs no second native image decoder.

The Compose tool has no network, published ports or credentials, runs UID/GID 1000,
uses a read-only root, 192 MiB tmpfs, 1 GiB memory/no extra swap, 2 CPUs, 32 PIDs,
no capabilities, no-new-privileges and no core dumps. A fail-closed inherited
kernel filter additionally denies new sockets/socket pairs/connect. Native parsing
refuses to start when this restriction is absent; it is never installed in the
API/ordinary worker. MOV demuxing is forced, only file/pipe protocols are allowed,
and external data references/absolute external tracks are disabled.

Each fresh FFprobe/FFmpeg/Tesseract child receives only an allowlisted environment,
10/11 CPU seconds, 1 GiB address-space bound, 2 MB per-file output bound, 32 open
files and a <=15-second wall deadline. The native pipeline has a 120-second budget;
timeouts kill only its newly created child process group. This may reject complex
but otherwise valid media rather than consuming unbounded local resources.
OCR is bounded to 16,000 characters/frame. Language-data SHA-256 and engine versions
participate in the processing profile; rebuilding with changed packages/data makes
drift explicit. There is no mutable runtime language/model installer.

This is not a hardened learner-code runner or a production security certification.
The dedicated authorized video queue, checkpoints/leases, tenant/project fences,
observable original retirement/cleanup and complete source/project object deletion
must be implemented before any product upload flag is introduced. The accepted
future one-hour original eligibility and retained selected-frame/OCR policy do
not create application storage in this stateless slice. Visual retrieval, frame
citations, scene-change recall and broader OCR review remain follow-up.
